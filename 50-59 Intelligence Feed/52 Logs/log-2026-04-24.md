# Log 2026-04-24: Eris Sovereign OS & Multi-Layer Security

## Resumen Ejecutivo
Evolución crítica completada. Eris dejó de ser un asistente personal aislado para convertirse en un **Sistema Operativo de Inteligencia Personal Soberana** con soporte multi-usuario, roles segregados y protección criptográfica robusta en todas las capas.

## Avances Principales

### 1. Sistema de Personalidad y Roles (Hestia / Hefesto / Eris)
- **Implementación de Roles Jerárquicos (`RoleSystem.ts`)**:
  - **🔱 Hestia (Admin Soberano)**: Control absoluto. Bóveda Obsidian, sistema de archivos, ejecución de bash, y asignación de roles. Con **Restricción de Red**: Hestia sólo puede operar desde `localhost` (IP local del servidor). Cualquier conexión externa (ej. desde el móvil) se degrada a `eris` silenciosamente.
  - **⚒️ Hefesto (Desarrollador)**: Acceso técnico y operativo (bash, web, file system), pero sin acceso a la bóveda personal.
  - **⚡ Eris (Usuario)**: Perfil estándar para chat e inferencia con integración al dashboard biométrico.
- **Persistencia de Roles**: Archivo `~/.eris/roles.json` administra la persistencia separando privilegios del código fuente. Se creó script interactivo de bootstrap (`setup-roles.ts`).
- **Prompt Dinámico**: `QueryEngine` ahora aísla la carga del `system-prompt` por usuario basándose en los roles (ej. `hestia.md` vs `system-prompt.md`) y el contexto personal (nombre, metas, idioma).

### 2. Autenticación Segura Zero-Knowledge
- **Refactorización de WS Handshake**: Eliminación de transmisión del PIN en la URL (`?pin=`). La conexión websocket ahora inicia con un mensaje `auth_required` desde el servidor, seguido de una respuesta `{ type: 'auth', pin: '...' }` como primer mensaje.
- **Protección Anti-Bruteforce (`AuthRateLimiter.ts`)**: Tracking de intentos de seguridad por perfil en `~/.eris/profiles/<id>/security.json`. Límite: 10 intentos fallidos para PIN y 5 para Llave de Recuperación. Exceder el umbral resulta en un bloqueo temporal de 15 minutos.

### 3. Dashboard Ejecutivo Mobile (Zero-Friction)
- **Navegación e Integración Biométrica**: UI/UX nativa con React Navigation Bottom Tabs. Corrección arquitectónica en la entrega de `pendingMessage` (Insights Biométricos de Eris) hacia el ChatScreen, migrando de `props` inestables a parámetros limpios de `route.params`.
- **Sincronización `Health Connect`**: Corrección de tipos de Health Connect (cambio a `HeartRateVariabilityRmssd`) en `MetricsService.ts` y estabilización del compilador TypeScript.

## Conclusión y Próximos Pasos
Se ha fundado la base estructural y de seguridad definitiva de Eris Sovereign. El ecosistema local ahora es capaz de alojar multi-usuarios seguros (ej. familiares) manteniendo la gobernanza y los secretos del sistema sellados exclusivamente para Hestia en el ordenador principal. Todo listo para la fase de integración profunda con la bóveda inteligente.
