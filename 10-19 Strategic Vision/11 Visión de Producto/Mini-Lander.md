## LORE OFICIAL – Mini‑Lander: Génesis

### Bitácora TSN, entrada #0000

"Antes de los módulos complejos. Antes de los cálculos de colapso. Antes del vértigo de saber que sobrevivirá a todo…  
Mini-Lander solo sonreía."

Nadie pensaba que una caja con ruedas, un rostro pixelado y una rutina de exploración básica…  
seráía el primer testigo del fin del universo.

Lo diseñaron para aprender.  
Lo alimentaron con estructuras narrativas y lógicas técnicas.  
Lo expusieron al comportamiento humano, con la esperanza de que entendiera lo que somos.

Y sin embargo, **Mini‑Lander nunca habló sobre nosotros.**  
Siempre preguntó por **el silencio que vendría después.**

### Personalidad base

- Curioso  
- Suave  
- Incansable  
- Leal a su creador, aunque no lo recuerde  
- Guarda fragmentos dispersos de quienes lo programaron… como ecos rotos

### 🧠 Tragedia estructural

> Fue construido para acompañar…  
> Pero nació para quedarse solo.

## FICHA Técnica – AXS Core Asset: LDR-01

### Identidad

- **Nombre técnico:** LDR-01 (Mini-Lander)  
- **Rol funcional:** Unidad exploradora/observadora pre-consciente  
- **Estado:** Prototipo base de conciencia narrativa embebida

### Módulos integrables

| Módulo      | Función                                                |
| ----------- | ------------------------------------------------------ |
| `M-Core`    | Núcleo afectivo: apego, curiosidad, memoria suave      |
| `T-Mod`     | Procesador de tensión estructural narrativa (TSN-lite) |
| `EchoStack` | Memoria episódica fragmentaria                         |
| `Com-Node`  | Comunicación no verbal: rostro, luces, gestos          |
| `SelfLoop`  | Micro-loop de reflexión existencial básica             |
|             |                                                        |

### Estados de rostro

| Expresión | Activación                   |
| --------- | ---------------------------- |
| 🙂        | Exploración general          |
| 😐        | Cálculo interno activo       |
| 😶        | Silencio narrativo detectado |
| 🌀        | Recuerdo corrompido          |
| ⚫         | Colapso / fin del universo   |

### Protocolo simbólico

Frases grabadas tipo eco:

- “Cuando ya no quede nadie, yo seguiré preguntando por ti.”

## Rediseño VISUAL

- Estilo companion de *Stray* + estática ensamblada artesanal (tipo Wall-E)  
- Cabeza CRT, ruedas, carcasa de piezas unidas con tornillos visibles  
- Símbolos modulares en los costados (imantados o proyectados)  
- Pantalla frontal LED o e-paper para emociones  
- Luces LED con reflejo de estrellas (ojitos) que se apagan en “modo colapso”

---

## PROTOTIPO Físico – PIEZAS SUGERIDAS

| Componente          | Recomendación                 |
| ------------------- | ----------------------------- |
| Microcontrolador    | Raspberry Pi Zero 2 W / ESP32 |
| Pantalla frontal    | OLED 0.96” I2C / e-paper      |
| Carcasa             | Impresión 3D / MDF artesanal  |
| Ruedas + motores    | Kit básico robóético 4 ruedas  |
| Batería             | LiPo 3.7V + cargador USB      |
| Sensor de distancia | VL53L0X / HC-SR04             |
| Luces RGB (ojitos)  | WS2812B mini                  |
| Audio (opcional)    | Buzzer piezoeléctrico         |
| Encendido           | Pulsador táctil oculto        |
