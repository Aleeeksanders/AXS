## 1. Núcleo del Agente y Backend (`C:\Proyectos\eris\`)
El componente central que orquesta la inteligencia artificial, el sistema de herramientas, la memoria y el servidor WebSocket.

- **`src/`**: Código fuente principal (Bun + TypeScript).
  - **`tools/`**: Colección de herramientas agénticas (BashTool, VaultHealerTool, SystemInfoTool, etc.).
  - **`services/`**: Lógica de negocio core:
    - `llm/`: Proveedores de modelos (OllamaProvider).
    - `security/`: Gestión de roles (Hestia, Eris), control de acceso y `AuthRateLimiter`.
    - `ContextCompressor.ts`: Compresión automática de contexto de conversaciones.
  - **`server.ts`**: Servidor HTTP y WebSocket, políticas Zero-Knowledge.
  - **`QueryEngine.ts`**: Motor principal de razonamiento e inferencia.
  - **`ui-ink.ts` / `ui-readline.ts`**: Interfaces de línea de comandos (CLI).
- **`web/`**: Sovereign Dashboard. Interfaz web para control ejecutivo y gestión visual del sistema.
- **`scripts/`**: Utilidades y scripts para exportación y generación de datasets.
- **`data/`**: Prompts del sistema (`system-prompt.md` para Eris, `prompts/ikaros.md` para Hestia).

> **Actualización 2026-10-12** (verificado contra el código):
> - **Datos de cada perfil:** `~/.eris/profiles/<perfil>/`, no `eris/data`. Ahí están las conversaciones, el perfil y las claves `kv_*.json`, todo cifrado desde el 2026-10-15.
> - **Carpetas nuevas en `src/services/`:**
>   - `vault/`: capa determinista sobre esta bóveda (índice, linter, briefing, panel AXS);
>   - `stt/` y `tts/`: voz;
>   - `gluco/`: bases de alimentos unificadas;
>   - `llm/ContextPlanner.ts`: contexto adaptativo.
> - **Servicios de salud y del día:** `DailyTargets`, `MealSchedule`, `NutritionDay`, `WaterToday`, `FoodParse`, `FoodResolve`, `FoodText`, `ReplyGuards`, `BaselineEngine`, `SymptomGuide`.
> - **Base de alimentos:** se genera con `scripts/build_food_db.ts` desde `scripts/food_db_spec.ts`.
> - Detalle por módulo: Valkyria, Eris.Core y Voz de Eris.

## 2. Interfaz Móvil Sovereign (`C:\Proyectos\eris-mobile\`)
Aplicación React Native (Expo) con experiencia nativa edge-to-edge para interactuar con Eris desde cualquier lugar.

- **`src/screens/`**: Vistas principales:
  - `ChatScreen.tsx`: Interfaz de chat principal con cajón de proyectos y streaming LLM.
  - `HomeScreen.tsx` / `LoginScreen.tsx`: Flujos de inicio y autenticación segura.
  - `MetricsScreen.tsx`: Visualización de métricas de salud y sistema.
  - `GlucoTrackScreen.tsx` / `NutritionScreen.tsx`: Dashboard de glucosa (scanner + histórico) y nutrición (Valkyria).
  - `TojiScreen.tsx`: Host del módulo Toji / FORGE (WebView + panel de chat nativo).
  - `HunterWalletScreen.tsx`: Host del módulo Hunter Wallet (finanzas, WebView + panel nativo).
  - `ProfileScreen.tsx`: Perfil, logout y cambio de cuenta.
- **`assets/`**: Apps WebView embebidas: `toji.html` (Toji, React precompilado) y `hunter-wallet.html` (Hunter Wallet, Preact+htm).
- **`src/components/`**: `PortalOverlay.tsx` (transición animada que envuelve Toji/Wallet/Eris).
- **`src/services/`**:
  - `WebSocketManager.ts`: Conexión en tiempo real con el servidor central.
  - `AuthStorage.ts`: Manejo seguro de credenciales locales.
  - `MetricsService.ts`: Integración con Android Health Connect para biometría.

> **Actualización 2026-10-12** (versión 1.36.0):

> - **Bienvenida y recorrido:** `src/screens/WelcomeFlow.tsx`, `src/components/tour/`.

## 3. Bóveda de Conocimiento AXS (`C:\Proyectos\AXS\`)
El "cerebro" y sistema de memoria de largo plazo de Eris. Bóveda Obsidian estructurada jerárquicamente:

- **`00-09 Management & Governance`**: Gobernanza — directrices centrales, manifiesto, identidades, mapas, dashboard, changelog y roadmaps.
- **`10-19 Strategic Vision`**: Planificación a largo plazo, TSN e ICA.
- **`20-29 R&D (The Forge)`**: **Toda la documentación técnica** — módulos de producto, RFCs de subsistemas, arquitectura del core, prototipos e I+D.
- **`30-39 GTM & Business Operations`**: Operaciones de negocio y "Go-To-Market".
- **`40-49 Standards & SOPs`**: Procedimientos operativos estándar.
- **`50-59 Intelligence Feed`**: Salida generada por Eris — `51 Updates` (reportes), `52 Logs` (logs diarios), `53 Decisions` (cristalizaciones del Protocolo Antigravity).
- **`90-99 Archivo`**: Almacenamiento histórico.

> Convenciones de escritura del vault (nomenclatura, wikilinks con ruta completa, frontmatter): ver `CLAUDE.md` en la raíz.
