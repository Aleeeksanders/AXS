# Capacidades y Características del Ecosistema AXS

**Ecosistema Soberano:** Eris y Hestia conforman un sistema de IA ejecutado 100% en local garantizando soberanía de datos absoluta.

El sistema es un motor agéntico avanzado diseñado para funcionar como una unidad de razonamiento autónomo, interfaz de conocimiento y ejecutor de tareas, el cual delega responsabilidades según la "Persona de IA" activa (Hestia como directora soberana, Eris como ejecutora pública).

---

## 1. Arquitectura Cognitiva (Dual-Mode Thinking)
El ecosistema adapta su capacidad cognitiva dinámicamente según la complejidad de la tarea mediante su sistema **Thinking Modes**:

- **Flash Mode (⚡)**: `qwen3.5:4b` con `temperature 0.3` y menos tokens — respuestas instantáneas, comandos sencillos, control de hardware.
- **Deep Mode (🧠)**: `qwen3.5:4b` con `temperature 0.6` y más tokens/contexto — razonamiento complejo, análisis de código, informes ejecutivos.
- *Nota: ambos modos corren sobre el **mismo modelo** (`qwen3.5:4b`); se diferencian por parámetros (temperatura, `maxTokens`, `enableThinking`), no por un modelo distinto.*
- **Streaming Dual**: La UI distingue visualmente entre "tokens de pensamiento" (razonamiento interno) y la respuesta final.

---

## 2. Sistema de Herramientas (Agentic Tooling)
Eris posee un `ToolRegistry` robusto que le otorga agencia sobre el sistema operativo, el entorno de red y su propia memoria:

**Gestión de Archivos y Sistema:**
- `BashTool`: Ejecución de comandos de terminal (PowerShell/Bash).
- `FileReadTool` / `FileWriteTool`: Lectura, modificación y creación de archivos en disco.
- `SystemInfoTool`: Recolección de métricas de hardware y OS.
- `OpenTool`: Apertura de archivos o URLs en el navegador/aplicación nativa.

**Aúnálisis y Conocimiento:**
- `WebSearchTool`: Búsqueda autónoma en internet y extracción de información.
- `CrystallizeTool`: Destilación y compresión de información extensa en resúmenes de alta densidad.
- `ExecutiveReportTool`: Creación de informes estructurados enviados al Sovereign Dashboard.
- `LogManagementTool`: Inspección y análisis de logs del sistema para debugging autónomo.

**Integración con Obsidian (AXS Vault):**
- `KnowledgeTool`: Consulta semántica/directa de la base de conocimientos.
- `VaultAuditTool`: Auditoría de la estructura de la bóveda (enlaces rotos, metadatos, etc.).
- `VaultHealerTool`: Auto-reparación (corrige codificaciones, enlaces huérfanos, metadatos).

**Salud y Biometría:**
- `GlucoTool`: Integración GlucoTrack — consulta glucosa en tiempo real, log de alimentos, predicciones metabólicas.
- `NutritionTool`: Búsqueda de alimentos por nombre o código de barras vía FatSecret API.

## 3. Interfaces de Acceso (Sovereign Interfaces)

1. **Sovereign Dashboard (Web)**: Interfaz web reactiva para "Executive Canvas", reportes y gestión de sesiones complejas.
2. **Eris Mobile (App)**: Aplicación React Native con:
   - Cajón lateral de proyectos (Project Drawer).
   - UI "Edge-to-Edge" optimizada para Android.
   - Integración biométrica mediante `Health Connect` (`MetricsService.ts`).
   - Dashboard GlucoTrack con gráfico histórico y scanner de código de barras.
3. **CLI Terminal**: Interfaces en línea de comandos (`ink` y `readline`) para interacción directa en consola.

---

## 4. Memoria y Compresión de Contexto
- **Compresión en Background (`ContextCompressor`)**: Cuando una conversación supera el umbral de mensajes, Eris comprime automáticamente el historial más antiguo usando el LLM en segundo plano.
- **Proyectos y Conversaciones**: Los chats se guardan, se asignan a proyectos específicos y se almacenan permanentemente en el `FileSystemAdapter`.

---

## 5. Seguridad y Zero-Knowledge
- **Arquitectura Aislada**: Política "Zero-Knowledge Multi-Profile". Cada usuario/perfil se autentica vía PIN.
- **RoleSystem (Ikaros → Hestia / Eris)**: El perfil **Ikaros** invoca a **Hestia** con acceso administrativo total. El perfil **Eris** (público) tiene acceso restringido al chat e inferencia.
- **AuthRateLimiter**: Protección integrada contra fuerza bruta en los sockets.
