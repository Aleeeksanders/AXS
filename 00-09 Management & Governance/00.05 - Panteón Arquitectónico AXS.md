# 🏛️ El Panteón Arquitectónico AXS

Este documento recoge la arquitectura completa y la nomenclatura conceptual del ecosistema **AXS** (Artificial eXperience System). Cada subsistema tiene un "naming" mitológico o conceptual que define su rol dentro de la arquitectura de producto.

> **Estado real:** 🟢 construido · 🟡 parcial · ⚪ concepto / planeado
> *Distingue lo que ya corre en código de lo que aún es visión.*

## 🌐 Capa Madre
- 🟢 **AXS**: El ecosistema completo. Holding tecnológico personal, plataforma de productos y sistema operativo integral. El paraguas bajo el que operan todos los módulos.
- 📖 **[[10-19 Strategic Vision/TSN.md|TSN]]**: *Fundamento teórico.* Marco filosófico, matemático y científico que sustenta todo el ecosistema (preprint vigente **v0.6.0**).

## 🖥️ Capa de Interfaz y Mando
- 🟡 **[[20-29 R&D (The Forge)/Nexus.md|Nexus]]**: *Centro de Mando.* Dashboard maestro y estado global. Existe el Sovereign Dashboard web (`eris/web`) + Home móvil; falta el mapa unificado.
- ⚪ **[[20-29 R&D (The Forge)/ZeroPoint.md|Zero Point]]**: *La Verdad Fuente (Baseline).* Estado óptimo de referencia (fisiológico, cognitivo, operativo). *"¿Dónde estás respecto a tu óptimo?"*

## 🧠 Capa de Agentes Centrales (Core)
- 🟢 **Eris**: *Jefa de Gabinete Soberana.* Interfaz cognitiva del sistema. Toma órdenes, orquesta módulos y presenta resultados.
  - 🟢 **[[20-29 R&D (The Forge)/Eris.Core.md|Eris.Core]]**: El motor de decisiones, routing y permisos (brainstem).
  - 🟢 **[[20-29 R&D (The Forge)/Eris.Memory.md|Eris.Memory]]**: Memoria persistente cifrada, historial contextual y perfil longitudinal.

## 📱 Capa de Producto (App móvil `eris-mobile`)
- 🟢 **[[20-29 R&D (The Forge)/Toji.md|Toji / FORGE]]**: Acondicionamiento físico gamificado estilo RPG (niveles, XP, árbol de skills, misiones). WebView.
- 🟢 **[[20-29 R&D (The Forge)/Hunter Wallet.md|Hunter Wallet]]**: Finanzas personales gamificadas (rango Hunter por sueldo/ahorro). WebView.
- 🟢 **[[20-29 R&D (The Forge)/GlucoTrack.md|GlucoTrack]]**: Glucosa en tiempo real (LibreLinkUp) + nutrición y scanner de código de barras.

## ⚙️ Subsistemas Especializados
- 🟢 **[[20-29 R&D (The Forge)/Valkyria.md|Valkyria]]**: *BioOS.* Subsistema metabólico y fisiológico (HRV, glucosa, sueño, estrés) para el score diario.
- ⚪ **[[20-29 R&D (The Forge)/NeuroSuite.md|NeuroSuite]]**: *Mental OS.* Cognición, focus, testing cognitivo y aprendizaje adaptativo.
- ⚪ **[[20-29 R&D (The Forge)/Reality Mindset.md|Reality Mindset]]**: *Doctrina / Framework Mental.* Verificación de sesgos, grounding y recalibración expectativa vs realidad.

## 🔒 Infraestructura y Telemetría
- 🟡 **[[20-29 R&D (The Forge)/Nyx.md|Nyx]]**: *Guardiana de la Sombra.* Seguridad y privacidad. Cifrado AES-256-GCM, `AuthRateLimiter` y roles ya operan; device-trust y biometric-unlock pendientes.
- 🟢 **[[20-29 R&D (The Forge)/Aether.md|Aether]]**: *Red Circulatoria.* Integraciones y conectividad (Health Connect, FatSecret, LibreLinkUp).
- ⚪ **[[20-29 R&D (The Forge)/Hecate.md|Hecate]]**: *Guardiana de los Caminos.* Orquestación avanzada, branching logic, rule engine y workflows condicionales.
- 🟡 **[[20-29 R&D (The Forge)/Argos.md|Argos]]**: *El de los Cien Ojos.* Telemetría, logging y observabilidad en background.
- ⚪ **[[20-29 R&D (The Forge)/AXS.Link.md|AXS.Link]]**: *Bus de Integración.* API Gateway / Service Bus entre módulos.

## 📡 Hardware y Mundo Físico
- ⚪ **[[20-29 R&D (The Forge)/GhostLine.md|GhostLine]]**: *Línea Empresarial de Venta Física.* Familia de wearables (GhostWatch, GhostRing, SmartLens, Audífonos).
- ⚪ **[[20-29 R&D (The Forge)/Lander.md|Lander]]** / **[[20-29 R&D (The Forge)/Mini-Lander.md|Mini-Lander]]**: *Companions / Edge Devices.* Avatares físicos robóticos e interfaces ambientales.
